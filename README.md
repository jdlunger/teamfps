# Team FPS prototype

A third-person, browser-based level for trying out team-shooter ideas.
Uses Three.js on WebGL2, built with Vite. All textures are generated in code.

## Run

    npm install
    npm run dev

Then open the URL Vite prints (http://localhost:5173 by default). Edits reload
automatically.

    npm run build     # production build in dist/
    npm run preview   # serve that build locally
    npm test          # plays the level's routes headlessly with a scripted walker

## Where things are

- `src/level.js`: the layout. Add or move blocks here; team B's half is generated by rotating team A's.
- `src/roster.js`: the playable characters: stats, abilities and select-screen text.
- `src/physics.js`: baseline movement tuning, collision, raycasts, and movement abilities (double jump, dash, jetpack, rolling, grapple).
- `src/combat.js`: weapons, plus the wandering characters you can hit.
- `src/world.js`: level mesh, procedural sky, lights and colours.
- `src/character.js`: character models and their animation.
- `src/main.js`: select screen, input, third-person camera, HUD and the game loop.

In the level, yellow surfaces are ramps and lighter tops are walkable. Grid lines are every 2m.

## Deploy

Pushing to `main` runs the tests, builds, and publishes to GitHub Pages through
`.github/workflows/pages.yml`. It needs enabling once: in the repository's
Settings > Pages, set Source to "GitHub Actions".
