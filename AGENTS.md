## Commands

    npm run dev     # dev server
    npm run build   # production build in dist/
    npm test        # headless level route tests

## Git

Always commit directly to `main`. Do not create branches.

Commit on every request, without asking first. This is a fast prototype, and the
user will ask for a revert if something is wrong.

Pushing to `main` deploys to GitHub Pages.
